# Icon source

Icons are downloaded from the selfh.st icon collection (repository `selfhst/icons`,
served via jsdelivr), which provides ready-made logos for self-hosted applications.
No icon was drawn or modified by hand. All three variants come from the same collection
so that the light and dark versions are consistent.

| File in this repo | Upstream file | Used for |
|---|---|---|
| `icon.svg` | `svg/node-red.svg` | Default (light mode) |
| `icon-light.svg` | `svg/node-red-dark.svg` | Dark-colored logo for light backgrounds |
| `icon-dark.svg` | `svg/node-red-light.svg` | Light-colored logo for dark mode |

Download URLs:

- https://cdn.jsdelivr.net/gh/selfhst/icons/svg/node-red.svg
- https://cdn.jsdelivr.net/gh/selfhst/icons/svg/node-red-dark.svg
- https://cdn.jsdelivr.net/gh/selfhst/icons/svg/node-red-light.svg
